# Kitabxana İdarəetmə Sistemi

Məlumat Strukturları fənni üzrə laboratoriya işi. Python 3 ilə yazılmış konsol tətbiqidir, əlavə paket tələb etmir.

## İşə salmaq

```
python3 kitabxana.py
```

İlk işə salınmada 50 kitablıq hazır kataloq avtomatik yüklənir. Kitablar `kitabxana.json` faylında saxlanılır (proqram onu özü yaradır).

## Əhatə olunan mövzular

| Mövzu | Tətbiqdə harada | Menyu |
|---|---|---|
| Array / Dynamic Array | Benchmark | 11 |
| Singly / Doubly Linked List | Benchmark, oxu siyahısı naviqasiyası | 10, 11 |
| Stack | Undo | 6 |
| Queue | Borc sorğuları | 7, 8 |
| Deque | Son baxılan kitablar | 9 |
| Hash Table (chaining) | ID ilə axtarış | 3, 12 |
| Binary Search Tree | Ada görə axtarış, əlifba sırası, silmə | 4, 5, 13 |

## Fayllar

- `kitabxana.py` — tətbiqin kodu
- `Hesabat_Kitabxana_Sistemi.docx` — hesabat (struktur seçimləri, ekran görüntüləri, performans nəticələri)
